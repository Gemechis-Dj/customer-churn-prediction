# Customer Churn Prediction System

A JupyterLab-friendly capstone project using the IBM Telco Customer Churn Dataset.

## Main Components
- end-to-end model training
- model interpretation
- Streamlit deployment app
- monitoring and improvement script

## Quick Start

Install packages:
```bash
pip install -r requirements.txt
```

Train the model:
```bash
python src/train_model.py
```

Run the app:
```bash
streamlit run app/app.py
```
